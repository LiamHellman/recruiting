# Trailhead dashboard

A dashboard for hiking-club trip sign-ups, written in TypeScript with React 18 and bundled with Vite. Styling is Tailwind CSS.

Unlike our old Angular app, this one has no server rendering. We considered Next.js but kept it a plain single-page app.

## Development

You need Node.js 20.

    npm install
    npm run dev

Unit tests run with Vitest.
